# Trees with three branch vertices are determined by their chromatic symmetric functions

Version DOI: [10.5281/zenodo.22813491](https://doi.org/10.5281/zenodo.22813491) · [All versions](https://doi.org/10.5281/zenodo.22813490)

[Manuscript PDF](three-branch-tree-csf.pdf) · [LaTeX](three-branch-tree-csf.tex) · [BibTeX](CITATION.bib) · [Verification](verification/README.md)

This preprint proves that every finite simple tree with exactly three vertices of degree at least three is determined, among all finite simple graphs, by its chromatic symmetric function. It advances the complete branch-vertex layer from two branch vertices to three.

The result does not resolve Stanley's conjecture for all trees and does not treat the layer with four or more branch vertices. The supplied Python scripts are finite exact regression and boundary checks for selected identities and exceptional cases; they are not a computer proof of the general theorem.

Status: internally reviewed preprint; external mathematical review and formal peer review are pending.

Topics: chromatic symmetric functions, tree reconstruction, graph theory, branch vertices, subtree polynomials, Stanley's conjecture.
