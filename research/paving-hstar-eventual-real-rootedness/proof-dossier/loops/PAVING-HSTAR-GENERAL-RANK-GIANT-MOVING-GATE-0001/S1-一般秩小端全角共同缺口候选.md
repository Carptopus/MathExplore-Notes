# 一般秩小端：全角共同缺口候选

2026-10-06。主线程一般机制候选，未独审。输入为前导一般全圆几何S1+R1
以及准确S2+R1的定义/局部导数，不以旧秩四一次余商替代本证明。
本页只付全角指数下界，尚未积分真实J、累计合并或actual h*。

## 1. 精确陈述与真实参数化

固定整数r>=5、d=r-1。写领先W=h exp(i theta)、C=cos theta，
theta∈(pi/r,pi/d)，K=(1-rp)h/(dp)>0，p=q/n。
准确角方程给

    K=-sin(r theta)/sin(d theta)，
    L=|1+K exp(i theta)|=sin(theta)/sin(d theta)，
    p=h/(r h+dK)， tau=t^r=h^d(h+K)/L， rho=1/L。

K随theta严格从0增至无穷。给定任意h,K>0均定义合法真实领先参数。
取D=|1-W|、lambda圆w(phi)=1-D exp(-i phi)，phi∈[0,pi]，
phi_*=arg(A/(1-W))，Delta=|phi-phi_*|。

候选存在只依赖r的epsilon_r,c_r>0，对全部0<h<=epsilon_r、K>0、
合法整数n,q及全部上半圆角，有

    q (|v(w(phi))|²/rho²-1)
       >= c_r n(1+K)/h * min(Delta²,h²)，            (1)
    E(phi)=q log(|v|/rho)
       >= (q/2)log[1+c_r n(1+K)/(q h)
                                      *min(Delta²,h²)]。

常数不共同于无界r。不将(1)的log粗截后声称支付真实振幅。

## 2. 准确归一化与远角正界

取u=phi/h、u_*=phi_*/h、zeta_h(u)=(1-D exp(-ihu))/h。
由tau L=h^d(h+K)，精确

    D_rel=|v|²/rho²-1
      ={ |L+(h+K)/zeta_h(u)^d|²-D² }/D²，
    F_(h,K)(u)=D_rel/[(r h+dK)(1+K)]，
    q D_rel=n h(1+K) F_(h,K)(u)。                   (2)

取epsilon_r小，D与1共同可比，1-D与h共同可比，且

    |zeta_h(u)|² >= c_r(1+u²)，0<=u<=pi/h。

这是|w|²=(1-D)²+2D(1-cos phi)及sin(phi/2)>=phi/pi的直接结果。
准确基准

    L²-D²=K²+2KC+2hC-h² >= c_r(h+K)(1+K)。          (3)

因C>=cos(pi/d)>0且h充分小，分别K<=1及K>=1即可检查(3)。
展开(2)的交叉项，以L<=1+K、正平方项不删负号，得到

    |L+(h+K)/zeta^d|²-D²
       >= L²-D²-2(1+K)(h+K)/|zeta|^d。

取仅依赖r的M足够大，使u>=M的第二项至多(3)的一半。
因为(rh+dK)与h+K共同可比，遂F>=c_r>0于全部u>=M。
不要求K有界，也不将无限角域压成有限样本。

## 3. 有界u紧化：保留h=0、K=0及K无穷的全部极限

在u∈[0,M]，h趋0时zeta_h趋C+i u，且其模有共同正下界。
以下极限连同前三阶u导数成立，由有限次幂、平方根的解析Taylor给出。

### 3.1 h=0，有限0<K<infinity

极限函数

    F_(0,K)(u)={|L+K/(C+i u)^d|²-1}/[dK(1+K)]。     (4)

其唯一零点u_0=sin theta，其他u>=0严格正。证明不是引用有限h的
非负极限来猜严格性，而是直接分类：置zeta=s exp(i psi)，
s=C/cos psi，0<=psi<pi/2。
沿竖线的导数符号来自

    d/du |L+K zeta^(-d)|²
       =-2dK |zeta|^(-2d-2)
                         [L Im(zeta^r)+K u]。

psi<pi/r时严格递减；第一负正弦区(pi/r,pi/d)的临界条件为

    -s^d sin(r psi)/sin psi=K/L。

左边严格递增：设delta=r psi-pi∈(0,psi)，其对数导数
r cot(delta)-cot(psi)+d tan(psi)>0。唯一解psi=theta、s=1，
准确身份L exp(i rtheta)+K exp(i theta)+1=0给最低值1。

psi>=pi/d时s>=C/cos(pi/d)>=1，K/L<1，所以
|L+K zeta^(-d)|>=L-K/s^d；该下界随psi严格增，且在pi/d为准确值。
pi/d不是临界点，因为s^d>K/L；故这一区不能取得新的最低值。
实端u0的值大于1，无穷端值L>1。得到(4)的严格唯一零点。

### 3.2 K趋无穷，允许h同时移动

除以K²，theta趋theta_d=pi/d，L/K趋1，得

    F_(h,infinity)(u)=|1+zeta_h(u)^(-d)|²/(dD²)。   (5)

其零点来自zeta_h^d=-1。zeta_h对应|1-h zeta|=D，
其中D=|1-h exp(i theta_d)|。单位d次根中只有领先共轭对
与该圆相交，上半角唯一u_*=phi_*/h，其他根的余弦严格更小。
该零点二阶非退化；u有界时无pole。

### 3.3 h,K同时趋0：必须保留比值而非只令K=0

写e=h+K、omega=K/(h+K)∈[0,1]，theta趋theta_r=pi/r、C趋C_r。
准确Taylor给

    F -> 2/[r-omega] * [C_r+Re(C_r+i u)^(-d)]。     (6)

分子一阶为2e[C_r+Re(C_r+i u)^(-d)]，分母为e(r-omega)+O(e²)。
这给角区所有h/K速度，不能删除omega端点。
(6)唯一零点u_r=sin(theta_r)：同一导数给psi<pi/r下降，
pi/r<psi<pi/d上升。psi>=pi/d时下界

    C_r-(cos(pi/d)/C_r)^d >0。

最后严格不等式等价r log cos(pi/r)>d log cos(pi/d)，
由s log cos(pi/s)在s>=4严格递增（导数log cos z+z tan z>0）给出。
故这不是把有限h非负性当成角区极限严格正性。

### 3.4 K=0，有限h>0的边界

此时theta=pi/r、p=1/r、rho=1。它只用于紧化，不套累计积分。
epsilon_r可另取小使D_uniform<D0，直接由D平方差的小h首项给出。
几何S1的角区分类仍成立：小角临界值>1；中角beta'<1/r给更大D；
分界theta=pi/r仅领先v=1；大角反三角排除不变。
正实外端若值<=1，其二阶系数q0*d[(1+q0)/D-d]<0，亦不是最低。
因此边界圆的唯一最低值仍为1，只在领先共轭点，F_(h,0)无额外零点。

## 4. 共同二阶正界而非仅点态紧性

所有有限h,K真实峰处F=F'=0，由准确反函数方差给

    partial_u² F(u_*)
       =2(1-p)(dK+rC)/(1+K) >= c_r>0。             (7)

上式对K=0、K无穷以及e=0/omega极限均连续保留。
用h∈[0,epsilon_r]、K/(1+K)∈[0,1]紧化，并在(h,K)=(0,0)
用(e,omega)坐标覆盖；(4)–(6)给真实解析延拓及共同有界前三阶u导数。
由于zeta模共同有界离0，这些是有限有理/Taylor表达的紧性，不是采样。

由(7)与共同三阶界，存在共同delta>0，在|u-u_*|<=delta有
F>=c_r(u-u_*)²。峰外的闭紧区域由§3各边界严格正性及有限内部的
全圆几何唯一性取得共同正最小值。联合§2 u>=M正界得

    F>=c_r min((u-u_*)²,1)。

代回(2)证明(1)。共轭给下半圆对应最近领先峰的界。
