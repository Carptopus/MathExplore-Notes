# 大端共同无界：有限多峰的高度与宽度预算

2026-10-06。固定r>=5、d=r-1；未独审，内部HOLD。
准确T、J、中央H与M见前导几何S2+R1；不覆盖actual h*。

## 1. 冻结序列与结论

h,K同时趋无穷，q、n-rq、n/h趋无穷；nh自动发散。
候选结论：准确T仍为领先两中央项实部加o(M)。Sigma在本域自动发散。
不要求K/h、K/h²或n/h超过任何log尺度。

记C=cos(theta)、L=|1+K exp(i theta)|，

    p=h/(rh+dK)， a=dK/(rh+dK)， tau=h^d(h+K)/L，
    alpha=(h+K)/h²， beta=K alpha， mu=q beta。

前导准确方差给

    n Re V / p² = q d(h+K)(dK+rC)/h² ~_r mu。

q alpha与n/h共同可比，因此q alpha、mu发散。
Kp与min(h,K)共同可比，Sigma=Kp sqrt(n Re V/p²)自动发散。
累计振幅B(w)=tau(1-w)/[w(w^r+tau)]，准确|B(W)|=(h+K)/(Kh)。
故|H|与|B(W)|/sqrt(mu)共同可比。

## 2. 准确极坐标式与共同多井极限

h大时D=|1-W|>1；上半w圆可写w=u exp(i psi)，0<=psi<=pi，

    u=cos psi+sqrt(D²-sin²psi)，
    u=h+cos psi-C+O_r(h^-1)。

连前三阶psi导数共同成立；lambda角和psi角的Jacobian绝对值与1共同可比。
令 b(psi)=(h+K)(h/u)^d。准确相对模为

    Drel=|v|²/rho²-1
        =[(b-L)²-D²+2Lb(1+cos(d psi))]/D²。          (1)

均匀于任意h,K共同发散速度，连前三阶导数有

    Drel/beta -> 2(1+cos(d psi))。                 (2)

具体界：b=(h+K)+O((h+K)/h)，非零阶导数O((h+K)/h)，L=K+O(1)。
将(b-L)²-D²的h²先相消，其C3范数除K(h+K)后至多
C[1/K+1/(Kh)+1/h²]；2Lb/[K(h+K)]=2+O(1/h+1/K)，D²/h²=1+O(1/h)。
这证明(2)，不是从原有限参数严格性猜测极限曲率。

theta趋pi/d。在固定小第一井I={|psi-pi/d|<delta}内，
真实Drel(theta)=Drel'(theta)=0；由(2)真实二阶导数/beta共同正。
共同Taylor给

    Drel >= c beta(psi-theta)²， psi∈I。           (3)

次要井是有限个psi_j=(2j+1)pi/d∈[0,pi]。它们在极限(2)也为零，
不能单凭(2)删除。需要保留下节的次阶径向高度。

## 3. 次要井的共同正高度

固定delta小，使I不含其他psi_j。若psi>=pi/d+delta，则
C-cos psi>=eta>0，u<=h-eta/2（h足够大）。所以

    b-(h+K) >= c(h+K)/h。

写e=L-K；准确 e-C=(1-C²)/(L+K+C)，于是

    (h+K-L)²-D² >= -C_r(h/K+1)。

又h+K-L=h-e>=h/2。由b的径向增加，

    (b-L)²-D² >= c(h+K)。                         (4)

因为负预算O(h/K+1)相对h+K趋0，无相对K/h要求。
同时Lb/D²与beta共同可比，1+cos(d psi)与
s(psi)²共同可比；s为到全部奇d角psi_j的最小距离。
(1)、(4)给该范围

    Drel >= c alpha+c beta s(psi)²。              (5)

在psi<=pi/d-delta范围，(2)极限无零点，给Drel>=c beta；
因K趋无穷，beta=K alpha且s有界，减小c后同样得到(5)。
因此(5)覆盖整个I补集；pi端点若为奇d角，仍用半个井积分。

## 4. 整圆振幅与背景，没有假pole穿圆

|w|与h共同可比，而tau/h^r=(h+K)/(hL)->0。故uniform假pole半径
tau^(1/r)=o(h)，远离本圆，整圆准确拆分

    J=B(w)v^(-q)-1/(1-v)

安全。直接由分子与分母给

    |B(w)|<=C(h+K)/(Kh)=C|B(W)|，
    |v(w)|<=C(1/h+1/K)->0， |1/(1-v)|<=2。         (6)

没有用对有限J的q粗高度覆盖近峰；也没有添加基线A^n。
rho=1/L<=C/K。背景完整积分除M至多

    C sqrt(mu) rho^q/|B(W)|
       <=C K sqrt(q) (C/K)^q ->0。                (7)

最后一步对任意q,K共同发散成立；没有n幂或h幂留在预算中。

## 5. 次要井完整积分相对消失

E=(q/2)log(1+Drel)。I内(3)给Student尾；变元
z=sqrt(q beta)(psi-theta)后，其核为(1+c z²/q)^(-q/2)。
q足够大时由固定可积Student核共同支配。取中央L缓增，I中中央以外
相对M的尾趋0；中央本身使用前导S2+R1准确Gaussian式。

I外由(5)，每个有限次要井的积分至多

    C integral_R (1+c alpha+c beta z²)^(-q/2) dz
      <= C/(sqrt(q beta)) (1+c alpha)^(-(q-1)/2)。

振幅(6)和归一化|H|~|B(W)|/sqrt(mu)抵消全部井宽，留下

    C(1+c alpha)^(-(q-1)/2) ->0。                 (8)

因为q趋无穷且q alpha与n/h共同可比并发散。alpha有界、趋0或趋无穷
均由(q-1)log(1+c alpha)趋无穷支付。有限井的总和仍趋0。
结合(7)、两中央峰及共轭，整个准确T满足冻结结论。
