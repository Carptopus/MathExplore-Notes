# S17 门下的完整原端保号

2026-10-07，主线程补接；内部 HOLD，待零信任审计。本页只修复 S19
审计指出的接合缺口：S17 控制的是单个最高-Euler累计，不能直接当成

## 0. 冻结命题

令 `n->infinity`、`r=r(n)->infinity`，`d=r-1`、`m=n-1`，`M` 为
连通 rank-`r` paving 拟阵，且每个有效超平面大小至多

    D-1,    D=n-ceil(n/r).

在原端相位网格

    n phi_r(t_j)=j pi,    kappa=(n-1)t_j,    t_j<=1/4

上，假设共同满足

    kappa/[r^8 log^2(2r)] -> infinity,
    kappa/[r^6 log^6(1+kappa)] -> infinity,
    r^2+r log(2r)=o(log(1/t_j)),
    C_*^r t_j log(1+kappa)=o(1/r),
    (C_1r)^r C_*^r t_j log(1+kappa)=o(1/r),     (0)

其中 `C_*` 可取得不小于 S17 的绝对常数，`C_1` 固定为下述 packing
估计中的绝对常数。则共同于全部上述 `M`，

    (-1)^j h*_M(-t_j^r)/R_r(t_j)^n >= 1/(2r)   (1)

最终成立。

这里倒数第二项只支付唯一临界超平面的 S17 累计；最后一项显式支付
非临界大超平面的共同求和。这个求和代价既不能从 S17 的裸 `o(1/r)`
自动推出，也不能仅由第三项推出，所以把它保留为独立门。

## 1. packing 分解不变

沿用 S13 §2，取

    delta=1/[1000(r+1)].

packing 不等式给

    # {H:s_H>delta n} <=(C_1 r)^r,              (3)
    sum_H (s_H)_(r-1)<=4^(r-1)n^(r-1).          (4)

对小超平面和低 Euler 层，S13 式 (6)--(8) 仍逐字成立：存在

    B_r=exp(C_2 r^2 log(2r))                    (5)

使最高 Euler 的小超平面部分及全部 `1<=h<=r-2` 的低 Euler 部分可由
同一指数生成函数估计。此步完全是有限组合 packing，不使用 S12 或
S17 的旧小 `t` 耦合门。

## 2. 小超平面和低 Euler 层在放宽门下仍可求和

S13 式 (9) 对最高 Euler 的小超平面给归一界

    B_r exp(-c kappa).                           (6)

低 Euler 层的 shift 参数满足

    Z_l/kappa<=2C_3 r t^(1/(r-1)).               (7)

由 (0) 第三项，`log(1/t)/r` 严格压倒 `log(2r)`，故 (7) 最终小于
`1/100`。于是 S13 式 (12) 给全部低 Euler 层及有限异常项的共同界

    B_r(1+kappa)^(2r)exp(-c kappa).              (8)

前两项门使

    kappa >> r^8 log^2(2r)

并且 `log(1+kappa)=o(kappa/r)`；故 (5)--(8) 的对数总损失为
`o(kappa)`，(6)、(8) 的和为 `o(1/r)`。

对 `k>delta n` 的尾，S13 的粗界为

    n^(2r) exp[-c n log(1/t)].                   (9)

由于 `r=o(n)` 且 `log(1/t)->infinity`，(9) 也是 `o(1/r)`。因此小
超平面、全部低 Euler 和一色尾在 S17 的放宽门下无需旧条件
`r log(1+kappa)=o(log(1/t))`。

## 3. 非临界大超平面的显式共同误差

设 `p=(r-1)/r`，并取 S13 的固定分界

    alpha_*=(p+1/2)/2.

除至多一个超平面外，所有大超平面都与临界比例 `p` 保持绝对间隙，
所以其标准化参数满足 `xi<=-c sqrt(kappa)`。对这样的单个累计，S17
只是把 S12 中央主分支的真实残数损失

    O(4^r t^(1/r)log(1+kappa))

替换成

    O(C_*^r t log(1+kappa));                    (10)

中央 Gaussian 尾、中央非主支、短边、中弧和远弧估计都不变。把
S12 §§3--4 的显式项保留下来，可写成

    |K_H|/R^n
      <= C_*^r t log(1+kappa)
       +P_r(kappa)exp(-c sqrt(kappa))
       +P_r(kappa)exp[-c kappa/r^2+C sqrt(kappa)]
       +P_r(kappa)exp[-c kappa/(r^4 log(2r))+C sqrt(kappa)],   (11)

其中 `deg P_r<=C_4r`、其系数对数至多 `C_4r^2log(2r)`。第一项乘
大超平面数后由 (0) 最后一项为 `o(1/r)`；其余各项乘 (3) 后由 (0) 前两项
和 `kappa>>r^8log^2(2r)` 为 `o(1/r)`。因此所有非临界大超平面
合计为 `o(1/r)`。这里使用的是可求和的显式误差账，而不是把 S17
对单个累计的统一 `o(1/r)` 直接乘 `(C_1r)^r`。

## 4. 唯一临界累计

packing 交界表明，与 `p` 不保持上述绝对间隙的有效超平面至多一个。
对这个累计直接使用 S17：在相位网格 `n phi_r(t_j)=j pi` 上，

    K_H/R^n
      =(2/r)(-1)^j Phi(xi/sqrt(v_+))+o(1/r),    xi<=0. (12)

S12 的复 Gaussian 估计给

    |Phi(xi/sqrt(v_+))|<=1/2,

故该累计的绝对值至多

    1/r+o(1/r).                                  (13)

uniform 主两分支在同一网格精确贡献 `2(-1)^j/r`。第 2--3 节的全部
其余校正为 `o(1/r)`。因此归一化后

    (-1)^j h*_M(-t_j^r)/R^n
      >=2/r-1/r-o(1/r)>=1/(2r),

即得 (1)。
