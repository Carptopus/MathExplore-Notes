# 特征值圆：准确累计积分与全远弧预算

2026-10-06。主线程候选，待新上下文证明审计。依赖S23+R1的准确GF、
S25的右驻点与S27的G几何；不继承这些文件的审计标签作为证明。
本页把全远弧问题改成标量有理函数，不宣称已支付所有移动序列或真实h*。

## 1. 精确域与符号

n>=2，整数q>=2，p=q/n<1/4，t>0，x=−t^4，A=1+t^4。
T=T_(4,n−1,q)是S23的最高补累计，不是完整单H或全部paving多项式。
W为唯一右上驻点，r=|W|，d=|1−W|，R=A/d，rho=|v_*|<1，
a=1−4p，V=p(1−p)(a+4p/W)。令tau=t^(4/3)、d3=sqrt(1−tau+tau²)。
S25/S27给R>R3=A/d3，所以0<d<d3<1+tau。

在lambda圆|lambda|=R上置

    lambda=R exp(i phi)，w=1−A/lambda=1−d exp(−i phi)，
    v(w)=(w³+t^4)/[w³(1−w)]。

phi_* = arg(A/(1−W))取(0,pi)；另一峰为−phi_*。
若w=0，含v的组合按下节有理延拓解释，不分别取无穷乘零。

## 2. 准确长度GF与无假极点的单积分

写X=Ay、w=1−X、Y=Xw³/(w³−x)=1/v。
直接由S23前q项GF求有限和，得到恒等式

    sum_m T_(4,m,q)y^m
      = A w³/(w^4−x) − A x Y^q/[w(w^4−x)]
      = lambda [Y^q/w + sum_(j=1..q−1)Y^j]，lambda=1/y。       (1)

第二式是有理身份而非仅在某个无穷级数区域成立。
例如q=1时空和0，lambda Y/w=A w²/(w³−x)；
一般q由(1−Y)有限几何和验证。第一式在w^4=x的两项必须相消，
不能把四次pole当作T的真实pole。

定义J_q(w)=Y^q/w+sum_(j=1..q−1)Y^j。
它在w=0解析：Y=w³(1−w)/(w³+t^4)，所以Y^q/w含w^(3q−1)。
J的唯一有限非平凡pole来自w³=−t^4；w=1不是pole。
在lambda变量对应三个三次pole，模至多R3<R。
lambda=0处，Y=O(w)、J=O(w^(q−1))、w=O(1/lambda)，
故lambda^(n−1)J=O(lambda^(n−q))；由于q<n/4，0亦解析。

把y系数圆反向映射到lambda大圆，再缩到R，得到准确等式

    T = (1/(2pi i)) integral_(|lambda|=R) lambda^(n−1)J_q(w)d lambda
      = (1/(2pi)) integral_(-pi..pi) lambda^n J_q(w)d phi。     (2)

整个组合可缩圆：三次pole都在内，没有漏掉残数。
不单独积分第一式中的uniform项；其左四次pole可能穿过R，
因此不能无条件把该项的圆积分记为0或指数小量。

## 3. 主鞍点与既有振幅准确接合

当v!=1、w!=0时，同一组合可写

    J_q = [x/(w^4(1−v))]v^(−q) − 1/(1−v)。                (3)

在v=1处(3)只能整体取延拓，不能拆成两条有pole的积分。
驻点W有v_*!=1，主项振幅为

    x/[W^4(1−v_*)]=(1−p)/(a W)。                          (4)

令z=log(lambda/lambda_*)，反函数log v在驻点的一阶导数为1/p，
二阶为−V/p³，因为d log lambda/d log v=eta、eta'=V。
因此log lambda−p log v的二阶导数是V/p²。
lambda角的Gaussian候选宽度是p/sqrt(n Re V)，不是v角的宽度。
若对应相对积分误差另行通过，主系数为

    H=p(1−p)/[a W sqrt(2pi n V)]，                         (5)

与S28完全相同。这里只核恒等式与尺度，不先声称完整渐近成立。

## 4. 全圆指数差直接由G给出

沿本圆h=|w|²=1+d²−2d cos phi，k=1−d²，z_h=1/h。
S27的准确展开给

    |v(w)|²/rho² = G(z_h)/G(1/r²)，
    G(z)=1+t^4−3t^4 d²z−3t^4 d²kz²+t^4(k³+t^4)z³。

两峰是全圆仅有的最小值，所以指数的实差准确为

    n log|lambda/lambda_*| − q log|v/v_*|
       = −(q/2)log[G(z_h)/G(1/r²)]。                      (6)

这不再依赖把四个竞争谱根逐一沿v圆延拓。
另一有用的准确形式为

    |v|²−rho²
      = t^4(h−r²)² [r²(2u−r²)+(u+r²)h]/(h³r^4)，
    u=r²+k=2 Re W。                                     (7)

中括号在实际h区间严格正，S27已给其完整证明。
但其最小值随参数退化，不能用逐点正性替代统一正常数。

## 5. 显式有限边界决定的远弧差值及安全积分界

取0<epsilon<min(phi_*,pi−phi_*)。删去两峰各epsilon邻域，余集E。
令候选角集合

    B_epsilon={0,pi,phi_*−epsilon,phi_*+epsilon}。

定义

    delta_epsilon = (1/2)log min_(phi in B_epsilon)
                       [G(1/h(phi))/G(1/r²)] >0。        (8)

d=1且phi0时按G(+infty)=+infty解释，不取其为最小。
(8)是E上的准确最小值：G'是二次式；除驻点极小值外，
正区间中至多还有一个极大值，没有另外的极小值。
在[0,pi]上h单调，删除峰邻域后，各闭段最小只在上述端点取到。

再定义显式安全高度

    B0 = rho*d*(1+d)² / [(d3−d)²(1+tau−d)]。             (9)

w³+t^4的三个根距w圆至少分别d3−d、d3−d、1+tau−d，
所以rho/|w v|=rho*d*|w|²/|w³+t^4|<=B0，w0亦按延拓。
在E上有rho/|v|<=exp(−delta_epsilon)。于是

    rho^q |Y^q/w| <= B0 exp(−(q−1)delta_epsilon)。

对有限和，|v|<=1时每一项rho^q|v|^(−j)<=exp(−q delta_epsilon)；
|v|>=1时每一项<=rho^q。因此准确远弧贡献满足

    |(1/(2pi)) integral_E lambda^n J_q dphi|
    <= R^n rho^(−q) [B0 exp(−(q−1)delta_epsilon)
           +(q−1){exp(−q delta_epsilon)+rho^q}]。         (10)

这里允许用sum替代max以保持共同安全界，不丢失v1相消。
除以候选单峰主量R^n rho^(−q)|H|，得到充分的相对尾门

    a*r*sqrt(2pi n |V|)/[p(1−p)]
    *[B0 exp(−(q−1)delta_epsilon)
        +(q−1){exp(−q delta_epsilon)+rho^q}] ->0。        (11)

(11)是具体充分条件，不是已证明所有合法序列满足的结论。
它提供可核的全局积分预算；不能把无穷小gap或多项式prefactor省略。
强一些的对数门可能排除真实可处理序列，须继续寻找更尖锐可积界。

并把整个远弧的指数缺口和安全绝对预算显化。
不能只用(11)再挑固定参数子族便称增长整类完成。

下一项是从(7)支付lambda角移动的可积相对尾，不强行保留(10)中
