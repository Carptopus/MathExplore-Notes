# 小端全部附加 H：双生成因子的相对预算

2026-10-06，冻结候选待独审。主结论只支付 r->0 的大小>=5附加坏 cap，
四点项可在 S42 经独立确认后另接；不覆盖紧 r、大 r、端盘或根数。

## 1. 范围与目标

沿 S39 参数：q、n−4q、nr、n/r、Sigma 全部趋无穷，r->0。
连通秩四 paving 的最大 H0 大小 n−q，p=q/n<1/4，
附加 H 的大小 v<=q+2，且不同 H 交至多两点。令 delta_v 是完整真实坏 cap
Euler 校正，u=t^4，A=1+u，d=|1−r exp(i theta)|，R=A/d。
主张

    sum_(H!=H0, v>=5) |delta_v(−u)|
                       =o(R^n rho^(−q)|H|)。              (1)

H（振幅）与超平面 H 的同符号沿前导约定；|H|~Sigma^(-1)。

## 2. 外部 packing 与准确正级数上界

每个附加 H 至少包含 v−2 个外部点。外部三元组不能属于两个 H，故

    sum_(v>=5) binom(v−2,3)<=binom(q,3)，
    sum_(v>=5) v³<=Cq³，数量<=Cq³。                       (2)

这里只用 v>=5，未把四点项藏在零权重中。
实际 Q_v(k) 计数内部 L=4k−J、外部 J<=k−1，坐标上界可忽略以得上界

    Q_v(k)<=sum_(J=0..k−1)
              binom(4k−J+v−1,4k−J)binom(J+n−v−1,J)。

u<1，故准确 Euler 有
|delta_v(−u)|<=A^n sum_(k>=1) Q_v(k)u^k。
选择 eta、zeta∈(0,1)，eta>=u^(1/4)、eta³zeta=u。
由于 L−3J>=4，eta^L zeta^J>=u^((L+J)/4)=u^k。
去掉总和模4和 L−3J 限制只增加正级数，得到两个合法界：

    sum_k Q_v(k)u^k <=(1−eta)^(-v)(1−zeta)^(-(n−v))； (3)

所有真实 L>=4，也可保留 L>=3。对 (1−eta)^(-v) 的三阶 Taylor 余项取上界，
再用(2)，外部坐标粗增到 n，给

    sum_(v>=5) sum_k Q_v(k)u^k
      <= C(q eta)^3 (1−eta)^(-(q+5))(1−zeta)^(-n)。      (4)

具体余项系数为 v(v+1)(v+2)/6，积分余项<=该系数乘
eta³(1−eta)^(-(v+3))；v+3<=q+5。
(3)(4)都是完整无限正级数，不把截断误差与数学主张混淆。

统一小 r 有 d^n<=exp(−c0 nr)，取固定 c0>0，且

    N0=nr=q(4r+3K)，u=r³(r+K)/S，S~1+K。

下面让生成因子的指数严格小于 c0 N0，或直接与 log d 比较。

## 3. K>=1：固定内部标记

取充分小固定 epsilon∈(0,1/4)，eta=epsilon，zeta=u/epsilon³。
r->0 时 u<=Cr³，所以最终 eta>=u^(1/4)、zeta<1/2，eta>zeta。
由(3)及数量界，正级数子和至多

    Cq³ exp[2epsilon(q+2)+2n u/epsilon³]。

q<=N0/(3K)<=N0/3，且 n u/(epsilon³ N0)<=Cr²/epsilon³->0。
先选 epsilon 再取 r 小，方括号<=c0 N0/2+O(1)。
故除 R^n 并乘 Sigma rho^q 后不超过

    C Sigma q³ exp(−c0 N0/2)。

S39 准确方差给 Sigma<=CK sqrt(q)，N0>=3qK，
所以 Sigma q³<=CN0^(7/2)。该预算共同趋零，K 任意大、q任意慢均允许。

## 4. K<1 且 p 小：三阶 packing 余项

先选充分小固定 delta>0，本节 p<delta。
取 eta=(u/p)^(1/4)=t p^(-1/4)，zeta=p eta。
eta>u^(1/4)，eta³zeta=u，且

    eta^4=r²(r+K)(4r+3K)/S<=Cr²，
    q eta/N0=p^(3/4)t/r<=C sqrt(p)。

因此 eta,zeta共同趋零，n zeta=q eta。式(4)的指数不超过
2(q+5)eta+2n zeta<=4q eta+10eta。
选 delta 使 4C sqrt(delta)<c0/2，则最终为 c0 N0/2+o(1)。
前因子 (q eta)^3<=C N0³，Sigma<=C sqrt(N0)，rho^q<=1，
所以相对误差<=CN0^(7/2)exp(−c0 N0/2)->0。
没有留下 q³ 或 n³；慢速 nr 发散也覆盖。

## 5. p>=delta：严格指数间隙与分离条件付数量

固定 delta<=p<1/4，K=ar/(3p)=O_delta(r)。
所以 theta->pi/4、S->1，t/r=[(1−p)/(3p)]^(1/4)(1+O_delta(r))，
log d=−r/sqrt(2)+O_delta(r²)，都对本区共同成立。
取

    eta=t[3(1−p)/p]^(1/4)，zeta=u/eta³。

两标记共同是 O_delta(r)，eta>zeta且eta>t。
在(3)的指数中 v<=q+2；因 eta>zeta，最大 v 的端点支付整个和。
用 −log(1−z)=z+O_delta(z²)，指数为

    n[p eta+(1−p)zeta]+O_delta(nr²+r)
      =nr[4 sqrt(p(1−p))/3+O_delta(r)]。

但对 p<=1/4，4sqrt(p(1−p))/3<=1/sqrt(3)<1/sqrt(2)。
因此 d^n 乘上述指数<=C exp(−c_delta N0)，保留真实严格余量。
数量粗界 Cn³ 给相对预算 C Sigma n³ exp(−c_delta N0)。

这里必须用分离条件，不将指数小量直接乘任意 n 幂：
K<=C_delta r，Sigma<=C K sqrt(N0)，Sigma->infinity 强迫
r sqrt(N0)->infinity，故 n=N0/r=o(N0^(3/2))；
再有 Sigma<=C sqrt(N0)。预算至多 C N0^5 exp(−c_delta N0)->0。
