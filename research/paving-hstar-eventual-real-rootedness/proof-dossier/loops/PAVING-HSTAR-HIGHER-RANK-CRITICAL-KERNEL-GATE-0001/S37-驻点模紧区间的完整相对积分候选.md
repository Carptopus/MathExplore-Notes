# 驻点模紧区间：完整相对积分

2026-10-06，候选待独审。最高T整圆门，非实际h*。

## 1. 量词

任意固定0<r_-<r_+<infinity，序列n,q满足

    q->infinity，n−4q->infinity，Sigma->infinity，
    r∈[r_-,r_+]。

符号S32/S34。K允许趋0、任意正值或趋无穷，t不另固定。
主张T_(4,n−1,q)(−t^4)=2 Re(lambda_*^n v_*^(−q)H)
加o(R^n rho^(−q)|H|)，H沿S34。
这里只对每固定r紧区间共同；不能以紧区间结果推r趋无穷。

## 2. 两峰共同邻域与振幅

以K∈[0,infinity]紧化，p=r/(4r+3K)，
C=cos theta从1/sqrt2连续变到1/2。
t^4=(1−p)r^4/[3p|1+K exp(i theta)|]连续延拓到正有限值；
K0时t=r，K无穷时t^4=r³。
两峰角phi_*在该紧化上保持距0、pi的共同正距。

在K0，v_*=1，右四次lambda pole正好是两峰；
对K>0它们在R圆外。对K小，圆到右pole的距离与K共同可比：
固定t对p变化有

    d log R/dp=p Re(1/V)>0。

在当前r紧化、K小区，此导数共同有正上下界，
1/4−p与K共同可比，故log(R4/R)与K共同可比。
左四次pole在K0有共同正径向差，始终不贴近峰邻域。

当K有正下界时，四次pole不能等于峰：否则v(W)=1且eta=1/4，
与p<1/4矛盾。K趋无穷的两峰W仍非零，
w^4+t^4在W极限等于r³(1−W)，后者不为0。
紧性因此给共同delta0>0，使两个峰各delta0角邻域内，

    |B(w)|<=C|B(W)|，
    |1/(1−v)|<=C p(1+K)|B(W)|，                         (2)
    B(w)=x/[w^4(1−v)]。

此处使用右pole在圆外的径向距离避免K小假pole；
不声称整圆都无四次pole。w0也远离两峰邻域。

## 3. 邻域外直接使用有限J，不拆假pole

删去两峰delta0邻域，得到F。沿参数紧化，F上

    |Y|、|Y/w|共同有界，Y=w³(1−w)/(w³+t^4)。

因为K有界时真实三次pole在R内严格有距；K趋无穷时
两右三次pole只能趋到已删除的两个峰，第三三次pole的模
A/(1+tau)仍比R3严格小，有共同距离；w0的Y/w可去。
从准确有限和J=Y^q/w+sum_(j=1..q−1)Y^j，得

    rho^q |J| <= C q [rho^q+exp(−(1−1/q)E(phi))]，phi∈F。 (3)

不按quartic partial fractions分别积分；圆穿左四次pole亦可用(3)。

## 4. 峰内非中央弧

选S34的缓增L，epsilon=Lp/sqrt(nReV)，两中央弧式已付。
在epsilon<=Delta<=delta0采用S32拆项及(2)。
S33给E>=q/2 log(1+c mu Delta²/q)：
r>=2时delta0取小于phi_*/2，故不套第三峰弱区；其他r用共同紧性。
乘|B(W)|、除以|H|，高项尾即

    C sqrt(mu) integral_(Delta>=epsilon)
                    (1+c mu Delta²/q)^(−q/2)dDelta ->0。

换y=sqrt(mu)Delta给共同Student尾，q与L趋无穷，
不将它粗估为峰外固定高度乘整圆长度。
次项−1/(1−v)的相对预算至多

    C sqrt(mu) p(1+K)rho^q ->0。                       (4)

K小有p与正常数可比、mu与n可比、
q log(1/rho)与Sigma sqrt(n)共同可比，Sigma发散支付(4)。
K在正紧区时q与n可比、rho共同小于1；
K大时sqrt(mu)<=C K sqrt(q)、p(1+K)<=C，rho<=C/K，亦支付(4)。

## 5. 全部远弧，包括穿过左四次pole的参数

由S33在F的共同角距离，K有界时E>=c n；
K大时，即使进入大r第三峰区，仍有

    E>= (q/2)log(1+c K)。                              (5)

这里r_+是固定的，可将大r第三峰n/(qr)换成常数乘K，
但不能在r无界时这样替换。
对(3)积分并除以|H|，上界为

    C Sigma q [rho^q+exp(−(1−1/q)inf_F E)]。           (6)

K有正下界且有界时，该式是固定n幂乘exp(−cn)，趋0。
K小趋0时Sigma<=C sqrt(n)，
rho^q<=exp(−c Sigma sqrt(n))，故Sigma n rho^q趋0；
Sigma n exp(−cn)也趋0，没有隐含q>=log n门。
K大时Sigma<=C K sqrt(q)，(5)给

    C K q^(3/2)[rho^q+(1+cK)^(−q/4)] ->0。

任意固定c>0、q足够大后，K(1+cK)^(−q/4)在K>=K0递减，
其最大值是固定K0上的指数小量；rho项同理。

## 6. 结论范围

S34中央相对式、§4峰内尾及§5全部F尾相加给§1完整T积分。
这里不需要基线A^n；直接有限J避开d1和穿左quartic圆的假pole。
完整参数覆盖剩r趋无穷，及未完成的宏观原端/实际低Euler和全部K/根数。
不得以本页紧性覆盖无界r，或把最高T改叫完整实际h*。
