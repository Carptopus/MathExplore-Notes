# 联合倒端三族数学修正

2026-10-07。本页只修正 `S22-发散巨H偏移的准确三次倒端桥候选.md`
中三个影响最终量词和极限表述的点；其余定义、计算和边界仍以 S22 为准。

## 1. 变动余数类

实际参数为

    a_n in {0,1,2}.

因此对任意复紧域，正确的统一结论是

    Q_n(z) - a_n! V_(3,a_n)(z) -> 0,

且各阶导数也一致收敛。只有在固定 `a` 的子列上，才可写成趋于单一核
`a! V_(3,a)`。由于可能的 `a` 只有三个，S22 中的共同界足以给出上述统一
结论，但不允许把混合子列写成共同趋于一个核。

## 2. 原点延拓

`Q_n` 在 `z=0` 由反转多项式延拓定义，并置

    Q_n(0)=1.

原点不通过带有 `Lambda/z` 的中间表示直接代入计算。含原点复紧盘上的
一致收敛，由 S22 的逐系数收敛与本页第 3 节的共同系数尾界直接支付；
不仅凭去心域收敛和原点点值作解析延拓推断。

## 3. 外部截断误差

外部截断中的 `O_j(1)` 是对每个外部组成因子的扣除，不是把含巨超平面权重
的整个 `L_j` 替换为绝对误差。若 `Delta B_u` 是第 `u` 个外部因子的截断
误差，则必须使用逐因子的相对误差界

    Delta L_j / \widetilde L_j
      <= max_u Delta B_u / B_u
      -> 0.

这一界与 S22 中的固定 `j` 顶项占优和全系数尾部估计共同给出经修正的
倒端复紧域收敛。

## 4. 生效范围

有效数学来源是 `S22 + S22R1`。它只支付 `b -> infinity` 时全部合法巨超平面
增长速度的归一倒端复紧域收敛，以及每个固定有限 `k` 的根传递。本页不支付
中带、全轴、新颖性或完整秩四定理。
