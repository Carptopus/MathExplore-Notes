# 分离全区域：完整单 H 的低 Euler 接合

## 1. 精确量词

沿 S23 准确单 H 多项式 p_single，s=n−q，p=q/n<1/4，x=−u，u=t^4>0。
沿 S32–S34 W、r、R、rho、V、H、Sigma。对任意序列

    q、n−4q、nr、n/r、Sigma ->infinity，

主张

    p_single(−t^4)−T_(4,n−1,q)(−t^4)
                     =o(R^n rho^(−q)|H|)。              (1)

完整单 H 是真实 S23(2) 对象，外加其他超平面不在量词内。
有界 Sigma、宏观原端 nr 有界、倒端 n/r 有界及全部根数亦不在本页。
若 (1) 通过，则可接 S36–S38 的分离最高 T 全积分；不能继承到有界 Sigma。

## 2. 两个低颜色标记在准确圆上共同小于一

置 X=1−w=A/lambda、d=|X|、h=|w|²、k=1−d²，C=cos theta。
为避免和整数次数混淆，本节 d 仅是圆几何长度。设

    D=4C²−1=rho，M=4C(1−2C²)，K=M/D，
    u=r³(Dr+M)，k=2rC−r²。

这些来自 S25 的准确驻点关系；S²=1+2KC+K²=D^(-2)。
对颜色 l=3、2 的 d_l=l−1，记

    Y_(d_l)=X w^(d_l)/(w^(d_l)+u)，v_(d_l)=1/Y_(d_l)。

两个准确因子为

    k²+u=4C²r²d²，k+u=r(Dr+2C)d²>0。                 (2)

二色标记（d_l=2）有

    d² |v_2|²=1+u−2u d²/h+u(k²+u)/h²。

在全部 h>0 配方取最小，得

    |v_2|²>=(k+u)²/[d²(k²+u)]
             =(1+Dr/(2C))²>1。                       (3)

一色标记（d_l=1）有

    d² |v_1|²=1+u+u(k+u)/h。

h<=(d+1)²、k+u>0 给

    |v_1|²>=1+r(Dr+2C)[1+u/(d+1)²]>1。               (4)

w0 用可去延拓 Y_l=0。于是整圆两个 |Y_l| 均<=1；
这是一项准确全角结构，不是谱采样结论。

## 3. 实际 band 与两个合法使用方式

沿 S23，h_e=1,2，l=4−h_e，d_l=3−h_e，

    R_(h_e)=sum_(j=0..h_e)(−1)^j binom(h_e,j) A^j T_(l,n−1−j,q)。

准确 GF 给

    R_(h_e)=(1/(2pi)) integral lambda^n w^(h_e) J_(d_l,q) dphi，
    J_(d_l,q)=Y_(d_l)^q/w+sum_(j=1..q−1)Y_(d_l)^j。     (5)

所有真实 d_l 次极点都在本 lambda 圆内，因 R2<R3<R；
lambda0 有 n−q 的正幂，w0 可去，故长度变换不漏残数。

保留有限和时，准确基线相消为

    w^(h_e)(J_(d_l,q)−X/w)
       =−u X w^(h_e−1)/(w^(d_l)+u)
                         sum_(ell=0..q−1)Y_(d_l)^ell。 (6)

被扣基线 w^(h_e−1)X 是 X 的至多 h_e 次多项式，
乘 lambda^n 后整圆角积分为零（n>h_e）；并非 S36 的 X/w 基线。

另一个完整身份是

    w^(h_e)J_(d_l,q)
      =X w³/(w^(4−h_e)+u)
        +u X w^(h_e−1)/(w^(4−h_e)+u) Y_(d_l)^q。      (7)

首项整圆积分恰是 W_(h_e)；仅在 §6 的分母共同远离圆时才拆开积分。
不能在穿过其假 pole 的参数下分别使用 (7)。

## 4. 小 r：n 前因子由真实 w 与 u 消去

取充分小的固定 r1>0。d~1，|w|>=c r，u<=C r³，
|w²+u|>=c|w|²，|w+u|>=c|w|。
用 (3)–(4) 的 |Y_l|<=1，(6) 的有限和绝对值<=q。
而 integral |w|^(-2)dphi=2pi/(1−d²)<=C/r。因此

    |R_1|/R^n<=C q u/r，|R_2|/R^n<=C q u。

记 N0=nr=q(4r+3K)，u=r³(r+K)/S，S~1+K；
真实权重 binom(s,h_e)<=C n^(h_e) 给

    n q u/r<=C N0²，n² q u<=C N0³。                  (8)

uniform 差权重<=C q n^(h_e−1)。准确残数给
|W_1|<=C u^(1/3)R3^n、|W_2|<=C u R2^n；
u^(1/3)<=Cr、R3<R、R2<R，因此对应预算<=C N0、C N0²。
孤立项差权重<=C q n²，q n² u³<=C N0³，且 R>1。
完整差的相对模不超过

    C Sigma(1+N0)³ rho^q。                             (9)

K<=1 时 Sigma<=C sqrt(N0)、q log(1/rho)~Sigma sqrt(N0)；
Sigma->infinity 支付 (9) 的全部 N0 幂。
K>=1 时 N0<=CqK、Sigma<=CK sqrt(q)，故 (9)
至多 C K^4(1+q)^(7/2)rho^q，共同趋零。
无 n 幂残留，不要求 q>=log n。

## 5. r 的任意正紧区间

u、w、d 有共同上下界（w 可为零但 (5) 已可去）。
(3)–(4) 给 |w^(h_e)J|<=Cq，准确 W 的谱模<=R。
所有权重及孤立项遂给

    |p_single−T|/[R^n rho^(−q)|H|]<=C Sigma n³rho^q。

K0 时 q~n、Sigma~K sqrt(n)，q log(1/rho)~Sigma sqrt(n)，
此项消失。K 在正紧区间时 q~n、rho共同小于1。
K无穷时 n<=CqK、Sigma<=CK sqrt(q)、rho<=1/K，
同样没有慢 q 留下的 n 前因子。

## 6. 大 r

令 N1=n/r->infinity，最终 r<=n。

### 6.1 K>=1

n=q(4+3K/r)<=Cq(1+K)，r<=n，u<=Cr³(1+r)<=Cn^4。
(5)、|Y_l|<=1 给 |w^(h_e)J|<=Cq r^(h_e)。
uniform W 的有限残数和孤立项也只有 n、r、u 的固定幂。
例如全部项统一粗界 C n^15 R^n 即可，因 R>R3>R2>1。
又 Sigma<=CK sqrt(q)，所以归一化至多

    C K(1+K)^15(1+q)^(31/2)rho^q->0。

rho<=(1+K+K²)^(-1/2)，固定幂被 q 次幂共同压制，允许 K 任意大。

### 6.2 K<1

此域 rho 有共同正下界，q~n、u~r^4、|w|~r。
(3)–(4) 给 |Y_2|<=C/r、|Y_1|<=C/r²。
(7) 的分母 w³+u、w²+u 均共同与 u 可比，故可合法拆项。
在 p_single 的组合中，所有 W 权重加上来自 R 的 W 权重不超过 C n^(h_e)。
uniform 谱有

    R3/R<=C r^(-1/3)，R2/R<=C r^(-1)，R>=c r³。

W 振幅是 u^(1/3) 或 u；由于 r<=n，它们乘权重、Sigma 仍只是 n 的固定幂。
这些 n 次谱比共同压制它们。
(7) 的剩余尾模<=C R^n r^(h_e)(C/r)^q，
q~n、Sigma<=C sqrt(n) 也共同支付全部 n 幂。
孤立项 C n³u³/R^n 同样趋零。这里不依赖 rho^q 支付 n 幂，
避免 K~1/r 且 r 很大时的错误粗界。
