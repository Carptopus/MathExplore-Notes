# 巨H补累计：三次极点与固定外部中带候选

2026-10-06。承接S22准确联合倒端，不继承为全轴。
本页冻结准确代数表示和每固定q的单H固定紧中带候选；q随n增长的
相位、移动两端、附加K及完整实际根性仍另付。全部内部HOLD。

## 1. 最高Euler项必须先相消，而不是分别估uniform与K

沿S10/S11的l色B_m，定义

    C_m(v,x)=v^m B_m(1/v,x)，
    T_(l,m,q)(x)=sum_(ell=0..q−1)[v^ell]C_m(v,x)，l>=2,q>=1。

真实单H最高保留项U_(4,n)−K_(4,n−1,s)恰为T_(4,n−1,q)，q=n−s。
这不是完整h*，但准确完成两个大项的相消。
写A=1−x、X=Ay、d=l−1、Z=(1−X)^d。S10准确GF给

    sum_m C_m(v,x)y^m
       = A(1−Xv)(1−X)^(d−1) / [(1−Xv)Z−x]。

逐v提取：ell0为A/[(1−X)(1−x/Z)]；ell>=1为
A/(1−X) (Xv)^ell (x/Z)/(1−x/Z)^(ell+1)。
把前q项相加，再将ell0中恒项合并，得到

    sum_m T_(l,m,q)y^m
      = A (1−X)^(d−1)/(Z−x)
        + A x sum_(ell=1..q−1)
            X^ell (1−X)^(d ell−1)/(Z−x)^(ell+1)。       (1)

空和为0。d>=1，所有分子均为多项式，X1的假极点消除。
因此l4的最高补累计只有三次分母(1−X)^3−x，而不是四次分母。
本身份对全部q成立；不把这个代数结论误写成q任意变化的统一渐近。

## 2. 完整单H的低Euler仍存在

令m=n−1、s=n−q。对h0..2，l=4−h，记

    W_h=sum_(j=0..h)(−1)^j binom(h,j) A^j U_(l,n−j)，
    R_h=sum_(j=0..h)(−1)^j binom(h,j) A^j T_(l,m−j,q)。

S11准确有限band表明W_h−E(Q_h)=R_h：长度和阈值同时降j，
所以外部截断q不变，不把它错降为q−j。
完整单H实际多项式准确为

    p_single =sum_(h=0..2)(−1)^h
       [(binom(n,h)−binom(s,h))W_h + binom(s,h)R_h]
       −(binom(n,3)−binom(s,3))x^3。                    (2)

h3的Q_h=W_h与E(W_h)=x3单独处理。不能只审(1)就宣称p_single根性。

## 3. 每固定q的三次极点及主相位

固定整数q>=2，n趋无穷；x=−t^4，t在任意固定正紧区间。
令tau=t^(4/3)，三次w根为tau exp(±iπ/3)及−tau；
lambda_w=A/(1−w)。在(1)的l4表达中，X0=1−w。
分母Z−x在X0附近为3w²X0(1−X/X0)+高阶项。
最高pole q的系数是

    w^(q−1) / [3^q X0]。

q1由首项同式；q>=2只有ell=q−1项产生该阶，系数不为0。
故准确系数可写

    T_(4,n−1,q)=sum_w lambda_w^n P_(q,w)(n)，

P是n的q−1次多项式，首系数w^(q−1)/[3^q(q−1)!]。
固定q及紧t域使其余系数共同有界，三次实分支模严格小于共轭对。

式(2)的其余项：h1的uniform差binom(n,1)−binom(s,1)=q固定，
其三色谱只给lambda_w^n乘有界因子，比主项低n^(q−1)；
h1的R_h是二次分母的固定阶极点乘n，h2及h3更低。
二色最大模sqrt(A)严格小于三色主模R3：
A−(1−tau+tau²)=tau(tau²−tau+1)>0。
又三色负实分支A/(1+tau)<R3，R3>1。
因此存在依q、紧区间的常数，令

    R3=A/sqrt(1−tau+tau²)，
    phi3=−arg(1−tau exp(iπ/3))，
    M=2 R3^n n^(q−1) tau^(q−1)/[3^q(q−1)!] >0，

有候选统一式

    p_single(−t^4)/M
       = cos(n phi3+(q−1)π/3)+O_q(1/n)。                (3)

指数低项的固定n幂已在紧区间被吸收。此处不要求所有辅助多项式根实。
phi3严格递增，从0趋2π/3；在网格n phi3+(q−1)π/3=jπ，
式(3)给最终严格交替，故每固定正紧区间内根数
n[phi3(t_right)−phi3(t_left)]/π−O_q(1)。
先固定端点后让端点趋0/无穷，得到每固定q单H实际D_*−o(n)个不同负根，
D_*=floor((2n+q−1)/3)，不排除仍有o(n)非实或重根。

## 4. 与倒端的索引校准，不是移动预算

由s+1=3c−a，准确(2n+q−1)/3=D_*+a/3。
形式上t趋无穷时phi3=2π/3−sin(π/3)/tau+O(tau^(−2))；
所以相位是(D_*+a/3)π−n sin(π/3)/tau+较低项。
q固定时S22的Lambda/n³趋1，tau~n/|z|^(1/3)，
正好对应V_(3,a)尾相位/网格。原端则自然尺度x~n^(−3)，
不是旧uniform的n^(−4)尺度。
这些对应只是准确索引和候选尺度，式(3)尚不包含移动t。
