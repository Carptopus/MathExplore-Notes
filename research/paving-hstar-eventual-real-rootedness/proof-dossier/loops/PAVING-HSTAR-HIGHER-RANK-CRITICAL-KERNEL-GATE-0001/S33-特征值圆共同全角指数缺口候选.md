# 特征值圆的共同全角指数缺口

2026-10-06，待独审候选。承接S32的准确圆与G比值；
本页证明共同指数控制，不声称已包含振幅积分或实际根性。

## 1. 精确陈述

沿S32，n>=2、整数q>=2、p=q/n<1/4、t>0。
W=r exp(i theta)，theta∈(pi/4,pi/3)，C=cos theta∈(1/2,1/sqrt(2))。
端点C=1/2或1/sqrt(2)仅用于连续紧化，不改变p的域。
置

    K=(1−4p)r/(3p)=4C(1−2C²)/(4C²−1)，
    mu=n(1+K)/r，phi_*=arg(A/(1−W))，
    Delta(phi)=|phi−phi_*|，0<=phi<=pi，
    E(phi)=q log(|v(w(phi))|/rho)。

存在绝对c>0，对所有这些参数：

1. 若0<r<=1/4，

       E(phi) >= (q/2)log[1+c mu/q * min(Delta(phi)²,r²)]。   (1)

2. 若1/4<=r<=2，

       E(phi) >= (q/2)log[1+c mu/q * Delta(phi)²]。          (2)

3. 若r>=2且phi>=phi_*/2，同(2)；若0<=phi<phi_*/2，

       E(phi) >= (q/2)log[1+c n/(q r)]。                    (3)

共轭给整个负角区。w0按无限指数延拓。
同时mu与n Re V/p²共同可比。

这里保留log，不能粗换成min(q,mu Delta²)后再用任意n幂吸收。
例如q增长很慢时，q log(1/p)才可能支付移动振幅的代价。

## 2. 无近似的相对差值

记d²=1+r²−2rC，h=1+d²−2d cos phi，u=2rC。
S32(7)给D_rel=|v|²/rho²−1。驻点方程给

    t^4=(1−p)r^4/|3p+(1−4p)W|，
    rho²=9p²/|3p+(1−4p)W|²。

所以准确等式为

    q D_rel = n(1−p)|1+K exp(i theta)|/3
                    * (h−r²)² L(h)/h³，                  (4)
    L(h)=r²(2u−r²)+(u+r²)h。

第一因子与n(1+K)以绝对常数可比。
E=(q/2)log(1+D_rel)，因此只须付(4)的共同下界。

## 3. 退化端点phi0不能靠固定正常数略去

令h_min=(d−1)²，L_min=L(h_min)。对所有r>0、
C∈[1/2,1/sqrt(2)]，有某绝对c0>0使

    L_min >= c0 r³[(2C−1)+(1+r)^(−2)]。
    L(h)=L_min+(r²+2rC)(h−h_min)。                       (5)

证明：准确写

    L_min = 2r³ N/(d+1−rC)，
    N=3C d+C+2C³−r(1+2C²)。                             (6)

分母严格正。S27的几何正性只使用2 Re W>=r，故在该闭C区间
对所有有限r仍给L_min>0；这一步可按S27§2的B(U)/L二次式重构。
r趋0时N/(d+1−rC)趋2C+C³，在闭C区间严格正。
因此有界r区的(5)来自正连续函数的正最小值，不需有限采样。

r趋无穷时，统一Taylor展开

    d=r−C+(1−C²)/(2r)+C(1−C²)/(2r²)+O(r^(−3))，
    N=(1−C)(2C−1)(r−C)+3C(1−C²)/(2r)+O(r^(−2))。

第二正项以共同正常数乘1/r为下界，余项可由共同大r吸收；
第一项非负，且r−C与r可比。分母与r可比，遂给(5)无穷端。

另由K表达式，(1+K)(2C−1)在闭C区间连续延拓，
C趋1/2时极限1/2，C=1/sqrt(2)时为sqrt(2)−1，内点严格正。
故

    L_min >= c1 r³/(1+K)。                              (7)

(7)保留theta与p的准确关系；把theta独立取pi/3后删除该关系会丢失
大型r的第三竞争峰gap，不能这样紧化。

## 4. 小r、紧r与大r分区

### 4.1 小r<=1/4

d与1可比，|d−1|与r可比，phi_*与r可比。
具体用1−d=(2rC−r²)/(1+d)>0及
sin phi_*=r sin theta/d、Re(1−W)>0即可。
因此对0<=phi<=pi，

    h 与 r²+phi² 可比，
    |h−r²| 与 (phi+r)|phi−phi_*| 可比。

后一式由cos差的两个sin因子以及phi_*与r可比给出，
整个角区(含phi接近pi)都保留正常数。
L(h)>=c r³+c r h>=c r(r²+phi²)，所以

    (h−r²)² L(h)/h³
        >= c r * [Delta/(r+phi)]²
        >= c r * min(Delta²/r²,1)。

代入(4)得q D_rel>=c mu min(Delta²,r²)，即(1)。

### 4.2 紧r∈[1/4,2]

r,C紧化；phi_*保持距0和pi为共同正距。
L(h)>0。除phi_*外，(h−r²)² L(h)/(h³ Delta²)严格正。
在phi_*用h'=2d sin phi_*=2r sin theta非零连续延拓，极限正。
在可能的d1、phi0、h0角点，L0>0、r>0，分子不趋0，
比值趋+infty，不能误判为0；可删去一共同小邻域后用紧性，
并直接在该邻域取共同正下界。
故该比值有共同正常数下界，与1/r可比，得到(2)。

### 4.3 大r>=2

d与r可比，h_min、h_max与r²可比；
phi_*∈[pi/2,3pi/4]。在该区间对应的cos差给

    |h−r²| >= c r Delta。

若phi>=phi_*/2，则phi>=pi/4，
h−h_min=2d(1−cos phi)>=c r。
由(5)有L(h)>=c r³；代入(4)得q D_rel>=c mu Delta²。

若phi<phi_*/2，则|cos phi−cos phi_*|>=c，故|h−r²|>=c r。
用(7)代替局部较强界，得到q D_rel>=c n/r，即(3)。
这里显式保留第三竞争峰；n/r有界时不能称其已经消失。

## 5. 局部尺度接合和仍未完成项

由a=3pK/r，

    n Re V/p² = n(1−p)(3K+4C)/r，与mu共同可比。

lambda角局部宽度因此为mu^(−1/2)。只在小r还需nr趋无穷来保证
phi_*比该宽度大：mu r²=n(1+K)r>=n r。
q趋无穷、n r趋无穷和n/r趋无穷时，(1)-(3)排除固定比例远区
成为同量级指数峰；并保留了中央到远区的具体log下界。

但指数控制仍不是相对积分控制：J_q的有限几何和、相近累计pole、
峰宽度归一化和端点高度必须与这些下界一起积分，不能粗乘任意n幂。
下一动作是按(1)-(3)分区支付实际J_q/|H|的可积相对尾，
并在pole合并区接S29+R1。宏观原端及全部实际校正另付。
