## 1. 精确量词

取任意序列整数n、q，p=q/n<1/4，

    q ->infinity，n−4q ->infinity，n r ->infinity，
    Sigma=K sqrt(n Re V) ->infinity，0<r<=r0。

这里可取固定绝对r0=1/1000；t>0允许任意移动，
K=a r/(3p)、a=1−4p、W=r exp(i theta)、V、rho、R沿S32。
该域自动有n/r趋无穷。主张完整最高补累计满足

    T_(4,n−1,q)(−t^4)
      = 2 Re[lambda_*^n v_*^(−q) H]
             + o(R^n rho^(−q)|H|)，                      (1)
    H=p(1−p)/(a W sqrt(2pi n V))。

误差相对单峰模，不是相对于可能为0的两峰实部。
无附加log(n)速度门；不覆盖Sigma有界的过渡（用S29+R1另接）。

## 2. 扣掉整圆可精确积分的基线，而不是粗估有限和

在lambda圆设X=A/lambda=1−w，Y=Xw³/(w³+t^4)=1/v。
S32准确身份进一步给

    J_q(w)−X/w
       = X x/[w(w³−x)] * sum_(ell=0..q−1)Y^ell          (2)
       = B(w)(v^(−q)−1)，
    B(w)=x/[w^4(1−v)]=t^4 X/[w(w^4+t^4)]。             (3)

(2)没有四次假pole，(3)必须整体取延拓。w0按有理延拓。
小r域d=|1−W|<1，故R=A/d>A；基线的准确整圆积分是

    (1/(2pi i)) integral lambda^(n−1) X/w d lambda = A^n。  (4)

不能记为0。但d<=1−c r给(A/R)^n=d^n<=exp(−c n r)。
这项指数小量及(2)的快衰减，替代错误的q高度乘整圆长度。

## 3. B的共同高度，不制造四次极点

置C=cos theta∈[1/2,1/sqrt2]。准确大小关系给

    t^4/r³=(1−p)(4r+3K)/(3|1+K exp(i theta)|)<=2，
    t>=r，1−r/t>=a(1−r)/(4(1−p))>=c a。               (5)

后一式由3p|1+K exp(i theta)|<=3p+a r以及
1−(1−z)^(1/4)>=z/4得到。r0保证t+r<1/10。
对四次根omega_j=t exp(i(pi/4+j pi/2))，记
d4=|1−t exp(i pi/4)|。右对有

    d²−d4²=(t−r)(sqrt2−t−r)+2r(1/sqrt2−C)>=c a t，

所以其到w圆|1−w|=d的距离至少c a t。
左对到该圆距离至少c t，因为d<1而|1−omega_left|>=1+c t。
四根间距共同为常数乘t。任一点若距某根<t/4，距其他三根至少c t；
若没有这样的近根，四个距离都至少t/4。于是整圆

    |w^4+t^4|>=c a t^4，|w|>=1−d>=c r，
    |B(w)|<=C0/(a r)<=C1 |B(W)|。                      (6)

因此小r圆上(3)可合法拆分，四次pole没有落在积分圆上；
实际积分仍使用(2)避免远角粗高度。不得把这个小r结论外推到一般r。

## 4. 参数预算必须抵消n，而不是要求q超过log n

记N=n r，mu=n(1+K)/r。准确身份为

    N=q(4r+3K)，
    q K=N a/3，
    Sigma²=N a²(1−p)(3K+4C)/9，
    rho=|1+K exp(i theta)|^(−1)，
    |H| 与 Sigma^(−1)共同可比。                       (7)

K<=1时，Sigma与a sqrt(N)共同可比，
q log(1/rho)与qK、Sigma sqrt(N)共同可比。
故Sigma<=C sqrt(N)，而Sigma sqrt(N)趋无穷。

K>=1时，Sigma<=C K sqrt(q)，
rho<=[1+K+K²]^(−1/2)，N/(1+K)<=Cq。
这些关系保留K任意发散，不能仅处理固定K。

## 5. 峰外小弧：Student尾与有限背景

取S34的缓增L，并进一步令L rho^q趋0。
两中央弧半宽epsilon=L p/sqrt(n Re V)，使epsilon=o(r)。
取固定角截断M r，M=100。小r几何给phi_*<=2r。
在|phi|<=M r但删去两中央弧的区域，采用(3)、(6)：

    rho^q |J−X/w|<=C |B(W)|[exp(−E(phi))+rho^q]。

除以|H|后，积分因子与sqrt(mu)共同可比。
在Delta<=r处，S33给

    exp(−E)<= (1+c mu Delta²/q)^(−q/2)。                (8)

换y=sqrt(mu)Delta，q趋无穷与L趋无穷使该Student尾积分趋0：
|y|<=sqrt(q)部分由exp(−c'y²)控制，另一部分的积分指数小于exp(−c''q)。
实际epsilon与L/sqrt(mu)共同可比，故该界确实排除整个中央弧。

在Delta>=r处，定义

    E0=(q/2)log[1+c(1+K)(4r+3K)]。                    (9)

S33给E>=E0，非中央小弧总预算至多

    C sqrt(N(1+K)) [exp(−E0)+rho^q] ->0。             (10)

核所有速度：K<=1有E0>=cN，背景rho^q<=exp(−c Sigma sqrt(N))；
K>=1有sqrt(N(1+K))<=C K sqrt(q)，
exp(−E0)<=[1+cK²]^(−q/2)。
任意固定c>0下K q^j[1+cK²]^(−q/4)对K>=1共同趋0，
例如q足够大后该函数随K递减，最大在K1；rho^q同理。

## 6. 大于M r的全部远角：四次衰减支付相对积分

当M r<=|phi|<=pi，|w|与|phi|共同可比，
(5)和M选择保证|w³+t^4|>=|w|³/2。由无假pole的(2)

    rho^q |J−X/w|
      <= C q t^4/|phi|^4
             [rho^q+exp(−(1−1/q)E(phi))]。

因为|phi−phi_*|>=r，E>=E0。积分全部远角并除以|H|，得到

    C Sigma * q t^4/r³
                 [rho^q+exp(−(1−1/q)E0)]
    <= C Sigma * N/(1+K)
                 [rho^q+exp(−(1−1/q)E0)] ->0。         (11)

K<=1时该界至多
C Sigma N[exp(−cN)+exp(−c Sigma sqrt(N))]，
由于Sigma<=C sqrt(N)、Sigma趋无穷，两项共同趋0。
后一项令z=Sigma sqrt(N)，最终sqrt(N)<=z，
Sigma N exp(−cz)=z sqrt(N)exp(−cz)<=z²exp(−cz)。
K>=1时至多C K q^(3/2)[rho^q+(1+cK²)^(−q/4)]，
按上一节共同趋0。这支付了q增长比log n慢的序列。
