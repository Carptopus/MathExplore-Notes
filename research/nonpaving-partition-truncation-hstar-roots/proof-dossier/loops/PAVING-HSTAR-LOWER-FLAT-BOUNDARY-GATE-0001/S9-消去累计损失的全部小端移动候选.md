# 消去累计损失：全部小端移动候选

2026-10-06，冻结待独审。对象与准确 H 为 S1、S5；最高帽与矩阵为 S6。
固定 alpha<1/2、max m_i<=alpha*n。目标覆盖任意 t->0、T=n*t->infinity，
不再要求 T/log(n)->infinity。以下不使用扩大的数表。

## 1. 从准确内容积分中删去不贡献的零跳路径

沿 S8 选择固定小 eta>0，alpha<beta<gamma<1/2，rho=exp(-eta*t)。
S8 全角域谱界为 spr M<=R4*exp(-beta*eta*t)。减小 eta 仍可成立，
另要求 eta*alpha<1/(8*sqrt(2))。

记 W=W_(n-1)^(2,2)，指定块大小 q<=alpha*n。准确恒等式给

    W(u)=tr(Q M(u)^n)/(2u)= (1/(2n))*d/du tr(M(u)^n),
    K_q=(1/(2*pi*i)) integral_(|u|=rho) W(u)*u^(-q)/(1-u) du。

多项式 W_base(u)=A^n*u^(n-1) 在该积分的贡献为零，因为 q<n。
故整个积分可准确替换 W 为 W-W_base，而不是丢弃帽的一项。
这个零跳路径相消将支付远角的累计分母。

## 2. 近角窗口：幂界只损失 T 的多项式

固定充分大的 L，先看 |theta|<=L*t，u=rho*exp(i*theta)。
由 M=D(u)(I+t*omega*P+t²*omega²*P²+t³*omega³*P³)，
有 ||M-I||<=C_L*t。酉 Schur 三角化后严格上三角各项也至多 C_L*t；
最多三次严格跳转的路径展开给

    ||M^n||<=C_L*(1+T)^3*R4^n*exp(-beta*eta*T)。

这里把 t 因子保留在跳转上，而非 S8 的 n³ 粗界。
W_base/R4^n 至多 C*exp(-(1/sqrt(2)+eta+o(1))*T)。
窗口长度 O_L(t)，而 |1-u|>=1-rho>=eta*t/2；内容因子 rho^(-q)
至多 exp(eta*alpha*T)。于是近角积分相对 R4^n 至多

    C_L*(1+T)^3*exp(-eta*(beta-alpha)*T)。           (Near)

## 3. 远角：二次谱式及零跳相消

S6 准确谱式因式分为两个二次方程

    (lambda-A)*(lambda-A*u)=sigma*i*t²*lambda²，sigma=+1 或 -1。

设 delta=|1-u|。在 |theta|>L*t 时 delta>=c*L*t；选 L 充分大，
两个中心 A、A*u 互不混合。每个二次式分别有一个根 lambda_0 近 A、
另一个 lambda_1 近 A*u，且共同满足

    |lambda_0-A|+|lambda_1-A*u|<=C*t²/delta，
    |lambda_0'|+|lambda_1'-A|<=C*t²/delta²。        (E)

可由两个互不相交的 C*t²/delta 圆上 Rouché 与隐式微分直接得到：
导数分母 2*(1-sigma*i*t²)*lambda-A*(1+u) 的模至少 c*delta。
常数共同于整个远角域；不含 1/t 的隐藏常数。

A/R4=exp(-t/sqrt(2)+O(t²))，而根离中心 O(t²/delta)<=C*t/L。
增加 L 并减小 t0，使中心和四根的模/R4 均至多 exp(-c0*t)，
可取固定 c0=1/(4*sqrt(2))。对两个 sigma 合并，使用
W=(1/2)*sum lambda^(n-1)*lambda'，并减去两个 marked 根的基线
A^n*u^(n-1)，幂差公式与 (E) 给

    |W-W_base|/R4^n
        <=C*(t²/delta²+n*t²/delta)*exp(-c0*T)。    (FarW)

第一项来自导数偏移，第二项来自 marked 根的幂差。
未标记根的导数已是 O(t²/delta²)，不产生未消掉的常数项。
|u| 与 A 在小端共同有界。远角 delta 与 |theta| 可比，因而

    integral_(|theta|>L*t) t²/delta³ dtheta <= C_L，
    integral_(|theta|>L*t) n*t²/delta² dtheta <= C_L*T。

加上 rho^(-q)，远角相对预算至多

    C_L*(1+T)*exp(-(c0-eta*alpha)*T)。             (Far)

(Near)+(Far) 证明全部最高帽 K_q/R4^n->0，只要求 T->infinity。

## 4. 低颜色不用粗 Shift：直接保留真实非负计数

对 S5 的 epsilon，s=sum epsilon=1或2，lcol=4-s，v=t^(4/lcol)。
真实 C_epsilon(l) 非负且不大于删去全部块上界后的准确计数
C(lcol*l-s+n-1,n-1)，负总和计为零。于是绝对收敛的原始级数给

    |R_epsilon(-t^4)|
        <= A^n*sum_l C(lcol*l-s+n-1,n-1)*t^(4l)
        <= v^s*(A/(1-v))^n。                     (Low)

第二步为单位根过滤：v^s/lcol 乘 sum_(nu^lcol=1)
nu^s*(1-nu*v)^(-n)，取模即可；s=2,lcol=2 也准确。
因此没有遗漏 l=0 或 l=1，也没有把计数替换成另一种拟阵。

外层重数至多 n^s，而 v=o(t)。相对 R4^n 的完整预算为

    C*(n*v)^s*exp(-c1*T) <= C*T^s*exp(-c1*T)，

因为 t<=1 时 v<=t；c1>0 共同。epsilon111 的孤立项为
abc*t^12/R4^n<=C*T^3*t^9*exp(-c1*T)，同样消失。
这是完整真实容斥的绝对上界，不需要低颜色帽的额外稳定性。
