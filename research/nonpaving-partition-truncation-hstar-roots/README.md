# Eventual simple negative roots for rank-four capacity-two partition truncations

Carptopus · carptopus@163.com · v0.1-beta · 7 October 2026

[Manuscript PDF](paper/main.pdf) · [LaTeX](paper/main.tex) · [Frozen Markdown](manuscript.md) · [BibTeX](CITATION.bib) · [Reproduction](REPRODUCE.md)

For every fixed 0 < alpha < 1/2, all sufficiently large partitions of n with largest block at most alpha*n have a rank-four capacity-two partition-truncation base polytope whose Ehrhart h-star polynomial has degree n-ceil(n/4) and distinct strictly negative real roots. The threshold is uniform over the number of blocks and the partition; blocks of sizes one and two and a growing number of blocks are allowed.

The threshold is not explicit. The result does not cover alpha=1/2, all small orders, other ranks or capacities, or arbitrary nonpaving matroids. Some members are paving, including the uniform-matroid case when all blocks have size at most two. The weighted multi-hypersimplex and split-matroid frameworks and the Adiprasito--Zhang uniform-matroid result are prior work, not claimed as new here.

The exact 37-file supporting proof closure is included under `proof-dossier/`, preserving original paths and bytes. Historical workflow labels within these selected dependencies are not public review claims.
