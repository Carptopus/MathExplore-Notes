# Verification notes

The manuscript uses finite exact certificates at two points: the Hilbert-basis
description of the Fano triangle cone and the conductor reduction for the
minimum-dimension theorem. All general linear-algebra obstructions are proved in
the manuscript; finite programs certify only the enumerated inputs explicitly
identified there.

## Core reproduction

From the MathExplore-Notes repository root, run:

```powershell
pwsh -NoProfile -File research\fano-half-rank-profiles\verification\run_all.ps1
```

The script uses `python` from `PATH`, SymPy 1.14 or a compatible later version,
and a C++17 `g++` compiler available on `PATH`. Use `-Python` to select another
interpreter. It writes compiled binaries only under the operating system's
temporary directory.
The runner first requires `__debug__=True` and `sys.flags.optimize=0`; it exits
before any certificate if Python assertions have been disabled.

Expected terminal lines include:

- `PASS: the fourteen primitive extreme rays are complete`;
- `PASS: the 78-element Hilbert basis is complete`;
- `PASS: explicit 4:3 counterexample and twice/triple-line-ray witnesses`;
- `PASS: 183 strengthened-cone Hilbert atoms have exact alternating-net witnesses`;
- `PASS: every pair of missing Hilbert atoms is generated by exact witnesses`;
- `holes=497 predicted=497`, followed by `unexpected=0 overpredicted=0`;
- `PASS: the thirty primitive anchored-chamber rays are complete`;
- `PASS: both exceptional scaled chamber rays have sharp exact witnesses`;
- `SATURATED` for the complete five- and six-dimensional low layers;
- `simplices=81`, `residue_union=226`, and `required_sharp_bases=812`;
- `PASS: frozen required sharp bases equal the conductor output`;
- `REQUIRED_BASE_COVER bases=812 errors=0`;
- `REFINED_CLASSIFICATION errors=0`; and
- `PASS: the finite-field trace construction is nondegenerate in all seven directions`.

## File roles

- `verify_fano_triangle_extreme_rays.cpp` and
  `verify_fano_triangle_hilbert_basis.py` certify the integral triangle cone.
- `verify_fano_43_counterexample.py` verifies the explicit multiples of a line
  jump and the counterexample to an abandoned candidate inequality.
- `verify_realized_strengthened_fano_atoms.py` reconstructs and checks the
  finite alternating-matrix witness library used by the semigroup proof.
- `verify_fano_profile_two_saturation.py` certifies all finite coupling rules
  used in the realizability proof.
- `probe_fano_profile_semigroup_holes.py` is a bounded destructive regression;
  it is not used to extrapolate the general theorem.
- `verify_fano_graded_conductor.py` certifies the 81-cone conductor reduction.
- `verify_fano_anchor_cone_extreme_rays.cpp` independently enumerates all 34
  chamber inequalities and proves that the hard-coded 30-ray input is complete.
- `verify_scaled_chamber_ray_witnesses.py` gives the missing sharp four- and
  six-dimensional witnesses for the two scaled height-one rays.
- `probe_n5_profile_saturation.cpp`, `probe_n6_profile_saturation.cpp`, and
  `probe_n7_noncollinear_full_exception.cpp` establish the complete low-layer
  witness input. They use fixed seeds only for witness discovery and exit with a
  failure code unless every target is covered.
- `verify_fano_graded_required_bases.py` proves that the frozen list of 812
  normalized bases exactly equals the conductor output.
- `verify_fano_graded_excess_bound.cpp` checks that the exact low-layer and
  fixed higher witness generators cover all 812 bases at sharp dimension.
- `verify_constant_height_five_field_net.py` verifies one finite-field trace
  construction required among the sharp bases.
- The remaining `probe_n*.cpp` files preserve fixed-seed witness searches used
  to locate low-dimensional matrices. Their hits are checked by exact binary
  rank, and every core probe now exits nonzero on `NO_HIT`; a failed search is
  never used as a nonexistence argument.

The exact source hashes are recorded in `SHA256SUMS`.
